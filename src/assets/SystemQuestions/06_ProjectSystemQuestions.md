System Number: 6
System Name: Project System
Capability: Deliver Value
System Scope: Defines how projects are planned, coordinated, delivered, and reviewed to achieve successful outcomes.

## 1. Project Overview

- What is this project?
- What is the project name?
- What is the project type?
- What is a short description of the project?

## 2. Project Purpose

- Why are we doing this?
- What is the primary objective?
- What should exist when the project is finished?
- How will success be measured?

## 3. Project Scope

- Record items included within the project.
- Record items intentionally excluded from the project.
- Document the primary limitations that may influence project planning and delivery.
- Record systems connected to the project.

## 4. Project Resources

- What resources support this project?
- What is the resource name?
- What is the resource type?
- How does the resource support the project?

## 5. Deliverables

- What must be created?
- What is the deliverable name?
- What is the description of the deliverable?
- What is the priority?
- What is the status?

## 6. Milestones

- What is the milestone name?
- What is the description of the milestone?
- How do you know the milestone has been achieved?
- What is the status?

## 7. Project Status

- Where are we now?
- What is the current phase?
- What is the current status?
- What is the next action required to move the project forward?
