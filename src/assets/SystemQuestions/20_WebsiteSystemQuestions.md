System Number: 20
System Name: Website System
Capability: Communicate
System Scope: Defines how the organization's website communicates information, supports its objectives, and serves its audiences.

## 1. Website Specification

- Why does the website exist?
- Who is the website for?
- What should the website achieve?
- What will be included in the website?

## 2. Content Architecture

- List the primary sections of the website.
- Describe how visitors move through the website.
- Describe how pages are organized.

## 3. Website Pages

- For each page, record page name, purpose, key content, and status.

## 4. Search Engine Optimization Plan

- Identify important search terms relevant to the website.
- Describe content optimization practices.
- Identify technical optimization considerations.

## 5. Analytics Plan

- Define the success metrics.
- Define the measurement tools.
- Define the reporting frequency.

## 6. Website Roadmap

- Define the website roadmap phases, including time period, focus, and deliverables.
