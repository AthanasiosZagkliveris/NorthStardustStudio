System Number: 21
System Name: Social Media System
Capability: Communicate
System Scope: Defines how the organization communicates, engages, and builds relationships through social media.

## 1. Audience Profiles

- For each audience group, record name, description, interests, goals, and challenges.

## 2. Platform Strategy

- For each platform, record platform name, purpose, primary audience, and content focus.

## 3. Content Types

- Define the content categories.
- Describe how each content type should be used.

## 4. Posting Calendar

- For each content item, record date, platform, content type, and status.

## 5. Bio Templates

- Provide a short bio for platforms with limited space.
- Provide a standard bio for most social media profiles.
- Provide an extended bio for platforms that allow longer descriptions.

## 6. Campaign Tracker

- For each campaign, record campaign name, goal, platforms, start date, end date, and status.

## 7. Analytics Tracker

- Define the performance metrics.
- Define the reporting frequency.
- Record observations, trends, opportunities, and recommended improvement actions.
