System Number: 2
System Name: Brand System
Capability: Foundation
System Scope: Defines how the organization expresses its identity consistently across every audience, channel, and experience.

## 1. Brand Kit

- Provide a short description of the visual identity.
- Select 3–7 characteristics that define the visual identity.
- List words that should guide design decisions.

## 2. Logo Specification

- List all approved logo versions.
- Identify the primary logo and when it should be used.
- Define the smallest recommended size.
- Describe the required space around the logo.
- Describe acceptable backgrounds.
- List incorrect logo usage practices to avoid.

## 3. Color System

- Define the primary colors, including name, hex, and usage.
- Define the secondary colors, including name, hex, and usage.
- Define the neutral colors, including name, hex, and usage.
- Explain when and how colors should be used.

## 4. Typography System

- Define the typefaces used, including name, purpose, and examples of use.
- Define the text hierarchy for Heading 1, Heading 2, Heading 3, and Body Text.

## 5. Visual Language

- Describe preferred imagery styles.
- Describe supporting graphic elements.
- Describe preferred layout style.
- Select characteristics that describe the visual style.

## 6. Brand Applications

- Describe branding requirements for the website.
- Describe branding requirements for social media profiles and content.
- Describe branding requirements for documents, reports, guides, and presentations.
- Describe branding requirements for digital and physical products.
- Describe branding requirements for marketing materials, advertisements, and campaigns.

## 7. Brand Rules

- List practices that should always be followed.
- List practices that should be avoided.
- Document approved exceptions.

## 8. Asset Inventory

- List all logo files and versions.
- List all icon files and versions.
- List approved font files and licenses.
- List illustrations, patterns, templates, and supporting graphics.
- List related brand documents.
- Record where brand assets are stored and maintained.
