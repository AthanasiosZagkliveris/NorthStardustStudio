# 07. Product Development System

## 01. Product Register

**Structure:** Table

**Number of Columns:** 5

**Columns:**
- Column 1: #
- Column 2: Product Name
- Column 3: Category
- Column 4: Status - Status Field
- Column 5: Launch Date
