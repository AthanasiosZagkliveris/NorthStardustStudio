# 13. Asset System

## 01. Assets

**Structure:** Table

**Number of Columns:** 8

**Columns:**
- Column 1: #
- Column 2: Asset Name
- Column 3: Asset Type
- Column 4: Purpose
- Column 5: Location
- Column 6: Responsible
- Column 7: Priority - Scale Field
- Column 8: Status - Status Field

## 02. Access

**Structure:** Table

**Number of Columns:** 5

**Columns:**
- Column 1: #
- Column 2: Asset
- Column 3: Access Level
- Column 4: Restrictions
- Column 5: Notes

## 03. Updates

**Structure:** Table

**Number of Columns:** 5

**Columns:**
- Column 1: #
- Column 2: Asset
- Column 3: Update
- Column 4: Date
- Column 5: Status - Status Field

## 04. Summary

**Structure:** Fixed Variant Text

**Number of Variants:** 5

**Variants:**
- Variant 1: Key Assets
- Variant 2: Active Assets
- Variant 3: Update Priorities
- Variant 4: Key Takeaway
- Variant 5: Next Review
