# 36. Glossary: the names used in the questionnaire documents (2026-10-29)

Status: **reference.** One line per term, with the document that explains it. The code and framework terms (Capability, System, Section, Field) are in `docs/ai/glossary.md`. Contents of this set: doc 35.

| Term | Meaning | See |
|---|---|---|

## 3. Buyer and user

| Term | Meaning | See |
|---|---|---|

| Direct Buyer | Buys exclusively for personal use | doc 33 section 5 |
