# The Frequency options

Generated by `npx vite-node scripts/catalogue/frequency-options.mjs` from the code (`BUSINESS_COST_FREQUENCIES`, the groups' lists in `AnswerUtils.ts`). Do not edit by hand.

## The default

The Frequency of a cost card (Resources, Partners & Suppliers, Delivery's Resources: Quantity, Price, currency, Frequency) offers **One-time, Monthly, Quarterly, Annually, Per unit, Per project, % of revenue** (seven). A group the lists do not know offers all seven. A group with one frequency shows it as text; a One-time one is not shown.

Other lists that are not this one:

| Where | Options |
|---|---|
| Legal expense (Cost, Frequency) | One time, Monthly, Annually |
| Strategy Metric (Frequency) | Weekly, Monthly, Quarterly, Semiannually, Annually |
| Financial model (forecast lines) | One-time, Monthly, Quarterly, Annually, Per project, Per unit, Per order, % of revenue, Other |
| Founder (Salary, Frequency) | Monthly, Annually (and the others its card offers: see the Founders card) |
